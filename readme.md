# Uči Hrvatski! - Croata Práctico

Una aplicación web interactiva y gamificada inspirada en Duolingo para aprender croata de forma progresiva (desde nivel A1 hasta B2).

## 🚀 Características

- **Ruta de Aprendizaje Progresiva:** Módulos ordenados que se desbloquean al completar los retos previos.
- **Curriculum Extenso:** Más de 100 expresiones clave de la vida real distribuidas en 7 módulos de 15 lecciones detalladas cada uno.
- **Dos Modos de Estudio por Módulo:**
  - *Aprender Vocabulario:* Fichas de estudio (*flashcards*) con audio nativo en croata, traducciones y contexto diario sin límite de vidas.
  - *Práctica / Quiz:* Ejercicios interactivos de opción múltiple para ganar XP, mantener rachas y poner a prueba tu memoria.
- **Sistema de Gamificación:**
  - Rachas de estudio y contador de XP.
  - Vidas limitadas por errores para dar emoción al aprendizaje.
  - Banner de recordatorio de repaso express cada 12 horas.
